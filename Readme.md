Finnvest

Finnvest is a simulation-first investment platform designed for responsive web and native mobile experiences.

Initial scope

* Simulated cryptoasset investing
* Simulated private-market investment intents
* Double-entry ledger architecture
* Account and eligibility controls
* Global-ready, compliance-first design

Safety and compliance

All investment activity is simulation-only. Live deposits, withdrawals, trading, and investment subscriptions must remain disabled until the applicable regulatory authorisations, legal reviews, and partner approvals have been verified.

Development status

Initial repository setup. This README does not indicate that the application has been deployed or approved for real-money operations.
